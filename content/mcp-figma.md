## Rôle et valeur ajoutée

> Le serveur MCP Figma donne à Claude un accès direct à tes fichiers. Il peut récupérer la structure exacte d'un écran (espacements, couleurs, composants) pour l'intégrer fidèlement, ou à l'inverse générer un écran dans Figma à partir d'une page web.

## Exemples de demandes

- *« Intègre cet écran : [lien Figma vers le frame] »*
- *« Crée dans Figma une maquette de cette page, en réutilisant les composants de notre bibliothèque. »*
- *« Liste les couleurs et typos utilisées dans ce fichier. »*

## Installation

Dans l'app Claude : **Paramètres → Connecteurs → Figma**, puis connecte ton compte. Colle ensuite simplement un lien `figma.com` dans la conversation.
