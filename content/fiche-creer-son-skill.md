## Qu'est-ce qu'un skill ?

> Un skill est un dossier contenant un fichier `SKILL.md` : une description (quand l'utiliser) et des instructions (comment faire). Claude le charge automatiquement quand ta demande correspond.

## Étapes

1. **Décris le besoin à Claude** : *« Aide-moi à créer un skill pour faire des audits d'accessibilité selon notre grille. »* Il te guidera avec le skill « skill-creator ».
2. **Teste-le** sur deux ou trois cas réels, et ajuste la description si le skill ne se déclenche pas au bon moment.
3. **Partage-le** : publie-le dans l'organisation Claude pour que toute l'équipe en profite, puis ajoute sa carte ici.

## Modèle

Le modèle de fichier `SKILL.md` est disponible dans l'onglet **Fichiers**.
